# 搜索文件和内容

适用版本：Fold 0.4.6 及更新版本。

## 入口

- 快捷键：`⌘F`
- 界面入口：顶部搜索框

## 搜索范围

- 默认搜索当前文件夹。
 点击「含子目录」可改为「仅当前层」，再点击可切回。
- 文件名由 Fold 直接检索。
- 正文依赖 macOS Spotlight 已索引内容。
- 已由 Fold 生成过的摘要也会被检索。

## 使用步骤

1. 进入要搜索的文件夹。
2. 按 `⌘F`。
3. 输入关键词。
4. 查看结果中的命中类型和路径。
5. 单击结果查看缩略图；回车或双击打开。
6. 右键点击「前往所在文件夹」，Fold 会定位并选中目标。

## 结果说明

| 标记 | 含义 |
| --- | --- |
| 文件名 | 名称中命中关键词 |
| 正文 | Spotlight 索引的文件内容命中 |
| 摘要 | Fold 已保存的摘要命中 |

## 搜索不到时的处理

1. 确认当前文件夹是否正确。
2. 确认是否需要开启「含子目录」。
3. 确认文件类型是否已被 Spotlight 索引。
4. 用 `⌘R` 刷新目录后重试。
5. 仍失败时记录文件类型、所在路径和关键词，提交 Issue。
