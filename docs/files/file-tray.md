# 文件托盘

适用版本：Fold 0.4.6 及更新版本。

## 它解决什么问题

文件托盘用来临时存放文件引用。你可以先从不同目录收集文件，再一次性拖到目标位置。放入托盘不会移动或复制原文件。

## 放入托盘

任选一种方式：

- 拖动所选文件到顶部暂存区域。
- 复制文件或文件夹后，打开暂存箱按 `⌘V`。
- 点击屏幕顶部暂存箱展开后的「粘贴」按钮。

## 查看和管理

- 点击顶部计数水滴，可切换列表、卡片和叠放。
- 列表和卡片模式支持框选后拖出。
- 叠放模式支持整组拖出。
- 可从状态栏撤销松手后的移动。

## 后台灵动岛

1. 打开「设置 → 通用 → 启用灵动岛」，或从菜单选择「Fold → 屏幕顶部暂存箱」。
2. 把文件拖到屏幕顶部，暂存箱展开。
3. 拖动右上角抓手调整左右位置，双击抓手恢复居中。
4. 位置按显示器保存。

## 边界

- 暂存箱登记的是引用，不是独立副本。
- 原文件被移动、重命名或删除后，引用可能失效。
- 外部应用拖入能否移动或复制，取决于来源应用提供的权限和操作类型。
