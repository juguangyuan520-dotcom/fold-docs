# 打开、选择和移动文件

适用版本：Fold 0.4.6 及更新版本。

## 打开文件

1. 在浏览区单击选中文件。
2. 双击文件，或按空格进入 Quick Look。
3. 再按一次空格关闭 Quick Look。

## 选择多项

| 目标 | 操作 |
| --- | --- |
| 选择单项 | 单击 |
| 加入已有选择 | 按住 `⌘` 单击 |
| 选择连续范围 | 单击起点，按住 `⇧` 单击终点 |
| 框选 | 在空白处拖动 |
| 显示或隐藏项目 | `⇧⌘.` |

## 复制、粘贴和移动

| 目标 | 操作 | 结果 |
| --- | --- | --- |
| 复制所选项目 | `⌘C` | 保存到系统剪贴板 |
| 粘贴到当前目录 | `⌘V` | 复制到当前文件夹 |
| 移动剪贴板项目 | `⌥⌘V` | 移到当前文件夹 |
| 重命名 | `F2` | 原地编辑名称 |

同名冲突时，Fold 会保留两份并自动编号，不会直接覆盖。

## 拖到其他应用

1. 选中一个或多个文件。
2. 拖到 Finder 或其他支持接收文件的应用。
3. 拖到 Finder 时，同卷默认移动，跨卷默认复制；按住 `Option` 可强制复制。

## 从其他应用拖入 Fold

1. 从 Finder、桌面或支持文件 URL 的应用拖动文件到 Fold。
2. 放到目录空白处可写入该目录。
3. 放到文件夹上并停留，目标高亮后继续向内拖，最后松手才执行。

## 撤销移动

在目录内松手完成移动后，可点击状态栏中的撤销入口。撤销只适用于 Fold 明确提供该提示的操作。
