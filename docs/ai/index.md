# Fold AI

[搜索文件和内容 ←](../files/search.md) | [手册首页](../index.md) | [设置 →](../settings/index.md) | [English](../en/ai/index.md)

适用版本：Fold 0.4.6 及更新版本。

## 能做什么

- 在对话绑定的目录及子目录内查找文件。
- 读取文本、Markdown、DOCX、有文字层的 PDF 和常见图片。
- 总结文件、文件夹或多份材料。
- 创建、读取、编辑、复制、移动、重命名和删除文件。
- 对明确请求直接执行；对有风险或复杂文本修改先生成预览。
- 在对话目录内运行受限沙箱 Shell 命令。

## 打开和退出

| 目标 | 操作 |
| --- | --- |
| 打开或关闭 AI 浮窗 | 点击标题栏右侧四叶草图标 |
| 全局唤起 | `⌃⇧Space`，需在设置中开启全局生效 |
| 收起浮窗 | `Esc`，或点击 Fold 主窗口内小窗外的空白处 |
| 新对话 | 点击浮窗左上角「+」 |
| 查看历史 | 点击浮窗左上角展开历史对话 |

## 对话目录

Fold AI 只能访问当前对话绑定的目录及其子目录。顶部可查看和确认范围。浏览到其他目录后，点击「切到当前目录」即可切换。

删除会移入系统废纸篓；复制或移动遇到同名目标会报错，不会覆盖。

## 模型配置

1. 打开「设置 → AI 能力 → 模型配置」。
2. 可使用第三方平台自动路由的免费模型，或选择自定义 API。
3. 自定义 API 需兼容 Chat Completions，并支持工具调用。
4. API Key 保存在 macOS 钥匙串，不写入设置文件。

## 文件摘要

入口：右键文件、文件夹或空白处，选择「AI 辅助」。

- 单个文件可生成摘要。
- 文件夹可选择「生成所有文件摘要」，任务会覆盖该文件夹及子文件夹中的支持文件。
- 左下角「摘要任务」显示完成数和等待数，可中断、继续或移除等待项。
- 打开已完成任务可查看带出处的简介。

默认本地内容提取支持 TXT、Markdown、CSV、TSV、有文字层的 PDF 和常见图片。扫描版 PDF 暂不能直接读取。

## 文本编辑

1. 让 AI 读取目标文件。
2. 要求生成修改预览，或直接下达明确编辑指令。
3. 预览模式下先检查差异，再确认。
4. 已提交的文本编辑可在对话卡片中撤销。

AI 会读取原文并校验版本，检测到外部修改冲突时会停止，不覆盖后续变化。

## 隐私边界

- 文件搜索、路径抽查和本地读取在本机进行。
- 模型需要用于回答的候选元数据和正文摘录会发送到已配置的模型服务。
- 会话、工具活动、待确认修改和撤销信息保存在本机 `~/Library/Application Support/Fold/Agent/Sessions/`。
