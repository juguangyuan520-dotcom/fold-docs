# 更新与版本记录

适用版本：Fold 0.4.6 及更新版本。

## 查看当前版本

任选一种入口：

- 「设置 → 关于」
- macOS 菜单栏「Fold → 关于 Fold」

## 检查更新

1. 进入「设置 → 关于」。
2. 点击「检查更新…」。
3. 有新版本时，按提示确认下载和安装。
4. 安装完成后重新查看版本号，确认已更新。

## 更新策略

- 启用 Sparkle 的发行包会在启动时检查，之后每天检查一次。
- 发现新版本后，设置左侧会显示「有新版本」。
- 下载和安装都由用户确认，不自动重启。
