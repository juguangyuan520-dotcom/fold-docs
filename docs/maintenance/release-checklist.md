# 手册发版检查

[故障排查 ←](troubleshooting.md) | [手册首页](../index.md) | [English](../en/maintenance/release-checklist.md)

每个 Fold 版本发布前执行。

## 检查项

1. 更新受影响页面的「适用版本」。
2. 界面入口、按钮名称或菜单变化必须更新步骤和截图。
3. 新增功能必须有任务型文档，不能只写功能名。
4. 删除或变更行为必须更新旧说明，避免两套说法。
5. 在 [更新与版本记录](update.md) 添加版本、构建号和用户可见变化。
6. 检查所有内部链接可打开。
7. 检查截图文件命名与版本一致。

## 截图命名

```text
{version}/{page}-{scene}.png
```

示例：

```text
0.4.6/settings-appearance.png
```

## 合并规则

- 文档 PR 必须在软件版本发布前合并。
- 无法确认技术细节时标注 `needs-verification`，不得猜测。
- 发布当天把「待发布」内容移入正文。

## 双语检查

1. 中文页面修改后，检查对应英文页面是否需要同步。
2. 两侧导航链接必须同时可用。
3. 未完成翻译时标注 `needs-translation`，不得删除中文行为说明。
