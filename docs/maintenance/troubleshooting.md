# 故障排查

[更新与版本记录 ←](update.md) | [手册首页](../index.md) | [手册发版检查 →](release-checklist.md) | [English](../en/maintenance/troubleshooting.md)

适用版本：Fold 0.4.6 及更新版本。

## 打不开或提示权限问题

1. 确认 macOS 版本不低于 14。
2. 打开「设置 → 文件夹访问」重新选择目标目录。
3. 若仍失败，进入 macOS「系统设置 → 隐私与安全性 → 文件与文件夹」。
4. 找到 Fold，恢复需要的文件访问权限。
5. 重启 Fold 后重试。

## 文件夹内容不刷新

1. 按 `⌘R`。
2. 返回上级目录后重新进入。
3. 确认文件没有被其他应用移动或删除。
4. 若只在外部应用修改后出现，记录文件类型和操作步骤并提交 Issue。

## 搜索不到文件

参见 [搜索](../files/search.md)。先确认搜索范围、关键词和 Spotlight 索引状态。

## AI 无法读取文件

1. 确认文件在当前对话目录及子目录内。
2. 确认格式受支持。
3. 扫描版 PDF 先用 OCR 转成有文字层的版本。
4. 确认自定义 API 兼容 Chat Completions 和工具调用。
5. 查看 AI 对话中的工具错误信息。

## 更新失败

1. 确认网络可访问更新地址。
2. 重新点击「检查更新…」。
3. 记录当前版本、目标版本和错误提示。
4. 若下载成功但安装失败，提交 Issue 并附系统版本和芯片架构。

## 提交 Issue 必须包含

- Fold 版本和构建号
- macOS 版本和芯片架构
- 复现步骤
- 预期结果
- 实际结果
- 相关截图或错误文本
