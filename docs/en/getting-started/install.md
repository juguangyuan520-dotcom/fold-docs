# Install and First Use

[Guide home](../index.md) | [Learn the main window →](interface.md) | [中文](../../getting-started/install.md)

Applies to Fold 0.4.6 and later.

## System Requirements

- macOS 14 or later
- Apple Silicon or Intel Mac
- Permission to access the files and folders you want to browse

## Install

1. Download the Fold installer from the official website.
2. Unzip it and drag Fold into Applications.
3. Open Fold.
4. If macOS cannot verify the developer, confirm the installer came from the official site, then follow the system prompt to allow it.

## What You See on First Launch

- Fold opens the Workbench by default.
- The Workbench shows recent items, favorite locations, and system locations.
- Sample files help you learn the interface and do not replace your local files.

## Grant File Access

1. Open Settings → Folder Access.
2. Choose the folder you want Fold to browse.
3. If access was previously denied, use the link to macOS System Settings → Privacy & Security → Files and Folders, then restore access for Fold.

## Acceptance Checks

- The main Fold window opens.
- You can enter one of your own folders.
- Double-clicking a text file opens or previews it.
