# Learn the Main Window

[Install and first use ←](install.md) | [Guide home](../index.md) | [Open, select, and move files →](../files/file-operations.md) | [中文](../../getting-started/interface.md)

Applies to Fold 0.4.6 and later.

## Main Areas

- **Workbench**: the default startup page with recent items, favorite locations, and system locations.
- **Browser area**: shows the current folder and supports icon, list, column, gallery, and glass-card views.
- **Left sidebar**: shows favorites, system locations, and the Open Folder entry.
- **Right inspector**: shows information about the selected file and can be collapsed.
- **Top toolbar**: provides navigation, search, view mode, sorting, and grouping controls.

## Common Controls

| Goal | Action |
| --- | --- |
| Return to the Workbench | Click the Workbench icon on the left side of the title bar |
| Open a folder | `⌘O` |
| Open settings | `⌘,` or click Settings in the lower left |
| Search | `⌘F` |
| Refresh a folder | `⌘R` |
| Collapse or restore the left sidebar | Click the sidebar button in the upper-left corner |

## View Modes

Use `⌘1` through `⌘5` to switch between:

1. Icons
2. List
3. Columns
4. Gallery
5. Glass cards

## Content Zoom

The lower-right control adjusts content zoom from 60% to 150%. Click the percentage to reset and save 100%. Fold remembers the last zoom level.
