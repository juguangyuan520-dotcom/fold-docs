# Updates and Release Notes

[Settings ←](../settings/index.md) | [Guide home](../index.md) | [Troubleshooting →](troubleshooting.md) | [中文](../../maintenance/update.md)

Applies to Fold 0.4.6 and later.

## Check the Current Version

Use either entry point:

- Settings → About
- macOS menu bar → Fold → About Fold

## Check for Updates

1. Open Settings → About.
2. Click Check for Updates.
3. If a new version is available, confirm the download and installation.
4. After installation, check the version number again.

## Update Behavior

- Sparkle-enabled distribution builds check at startup and once per day afterward.
- When a new version is found, Settings shows New Version Available.
- Download and installation require user confirmation; Fold does not restart automatically.
