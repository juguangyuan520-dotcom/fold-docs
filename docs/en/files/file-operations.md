# Open, Select, and Move Files

[Learn the main window ←](../../getting-started/interface.md) | [Guide home](../index.md) | [Use the file tray →](file-tray.md) | [中文](../../files/file-operations.md)

Applies to Fold 0.4.6 and later.

## Open a File

1. Select a file in the browser area.
2. Double-click it, or press Space to open Quick Look.
3. Press Space again to close Quick Look.

## Select Multiple Items

| Goal | Action |
| --- | --- |
| Select one item | Click it |
| Add to the selection | Hold `⌘` and click |
| Select a consecutive range | Click the first item, then hold `⇧` and click the last |
| Rubber-band select | Drag in an empty area |
| Show or hide items | `⇧⌘.` |

## Copy, Paste, and Move

| Goal | Action | Result |
| --- | --- | --- |
| Copy selected items | `⌘C` | Save to the system clipboard |
| Paste into the current folder | `⌘V` | Copy into the folder |
| Move clipboard items | `⌥⌘V` | Move into the folder |
| Rename | `F2` | Edit the name in place |

When a name conflicts, Fold keeps both items and adds a number instead of overwriting.

## Drag to Another App

1. Select one or more files.
2. Drag them to Finder or another app that accepts files.
3. Finder moves on the same volume and copies across volumes by default. Hold `Option` to force a copy.

## Drag Files into Fold

1. Drag files from Finder, the Desktop, or an app that provides file URLs.
2. Drop them in a folder's empty area to write to that folder.
3. Hover over a folder until it highlights, continue dragging into it, then release to complete the action.

## Undo a Move

After releasing a move inside a folder, use the Undo control in the status bar. Undo applies only when Fold explicitly offers it.
