# 认识主界面

适用版本：Fold 0.4.6 及更新版本。

## 主区域

- **工作台**：应用启动后的默认页面，包含最近浏览、常用位置和系统位置。
- **文件夹浏览区**：显示当前目录内容，可切换图标、列表、分栏、图库和玻璃卡片视图。
- **左侧栏**：显示常用位置、系统位置和「打开文件夹」入口。
- **右侧详情栏**：显示选中文件的信息，默认可收起。
- **顶部工具栏**：提供导航、搜索、展示方式、排序和分组设置。

## 常用入口

| 目标 | 操作 |
| --- | --- |
| 返回工作台 | 点击标题栏左侧的工作台图标 |
| 打开文件夹 | `⌘O` |
| 打开设置 | `⌘,` 或点击左下角「设置」 |
| 搜索 | `⌘F` |
| 刷新目录 | `⌘R` |
| 收起或恢复左侧栏 | 点击窗口左上角侧栏按钮 |

## 视图切换

使用 `⌘1` 到 `⌘5` 依次切换：

1. 图标
2. 列表
3. 分栏
4. 图库
5. 玻璃卡片

## 内容缩放

右下角可把内容缩放调整为 60%–150%。点击百分比会恢复并保存为 100%。Fold 会记住上次比例。
