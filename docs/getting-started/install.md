# 安装与首次使用

适用版本：Fold 0.4.6 及更新版本。

## 系统要求

- macOS 14 或更新版本
- Apple Silicon 或 Intel Mac
- 需要访问的文件或文件夹权限

## 安装

1. 从官网下载 Fold 安装包。
2. 解压并拖入「应用程序」。
3. 打开 Fold。
4. 如果 macOS 提示无法验证开发者，先确认安装包来自官网，再按系统提示允许打开。

## 首次启动会看到什么

- 默认打开「工作台」。
- 工作台显示最近浏览、常用位置和系统位置。
- 示例文件用于了解界面，不会替代你的本地文件。

## 给 Fold 文件访问权限

1. 打开「设置 → 文件夹访问」。
2. 点击选择文件夹，授权你希望 Fold 浏览的目录。
3. 如果之前拒绝过权限，按页面入口进入 macOS「系统设置 → 隐私与安全性 → 文件与文件夹」，为 Fold 恢复访问。

## 验收标准

- 能打开 Fold 主窗口。
- 能进入一个你自己的文件夹。
- 双击文本文件能打开或预览。
