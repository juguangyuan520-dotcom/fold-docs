# 设置

[Fold AI ←](../ai/index.md) | [手册首页](../index.md) | [更新与版本记录 →](../maintenance/update.md) | [English](../en/settings/index.md)

适用版本：Fold 0.4.6 及更新版本。

## 入口

- 快捷键：`⌘,`
- 界面入口：左下角「设置」

## 通用

| 设置 | 作用 |
| --- | --- |
| 默认文件夹 | 启动时直接打开指定目录，替代工作台 |
| 启用灵动岛 | 在屏幕顶部使用同一个暂存箱 |
| AI 快捷键 | 修改 Fold AI 唤起快捷键 |
| 全局生效 | 允许从其他应用唤起 AI |

## 外观

- 设置玻璃卡片配色、封面纹理、项目数和悬停预览。
- 可开启减少动效。
- 示例区可直接预览效果。
- 支持恢复默认值。

## 文件夹访问

通过 macOS 文件选择器授权指定目录。若此前拒绝过系统权限，需要到 macOS「系统设置 → 隐私与安全性 → 文件与文件夹」恢复。

## AI 能力

- 切换本地内容提取或大模型模式。
- 配置供应商、模型、用户 Prompt、工具调用轮数。
- API Key 保存在 macOS 钥匙串。

## 数据保存位置

| 数据 | 位置 |
| --- | --- |
| 最近浏览、常用位置、外观和浏览设置 | `~/Documents/Fold/settings.json` |
| 摘要数据库 | `~/Library/Application Support/Fold/Summaries/summaries.sqlite` |
| AI 会话 | `~/Library/Application Support/Fold/Agent/Sessions/` |
| API Key | macOS 钥匙串 |
